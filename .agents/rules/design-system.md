# KostKita Design System

## Design Philosophy
Anthropic-inspired editorial minimalism interpreted as an original fintech identity.

## Visual Direction
- Warm off-white backgrounds.
- Charcoal typography.
- Muted green accent.
- Restrained red and amber.
- Subtle borders.
- Generous whitespace.
- Strong typography hierarchy.
- Consistent spacing.
- Clean financial tables.
- Tabular numerical alignment.

## Component Standards
- Tailwind CSS.
- shadcn/ui.
- Lucide icons.
- Motion animations.

## UX Principles
- Clear primary actions.
- Explain financial calculations.
- Distinguish shared and personal expenses.
- Clearly display who paid and who owes.
- Never use color alone to convey financial meaning.
- Support desktop and mobile.
- Include hover, focus, disabled, loading, and error states.

## Avoid
- Excessive gradients.
- Glassmorphism.
- Excessive shadows.
- Unnecessary decorative elements.
- Generic SaaS dashboard appearance.

Do not copy Claude branding or proprietary visual assets.
