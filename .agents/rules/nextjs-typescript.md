# Next.js & TypeScript Rules

- Use Next.js App Router.
- Use TypeScript strict mode.
- Prefer Server Components.
- Use Client Components only when necessary.
- Keep business logic outside React components.
- Validate external input using Zod.
- Enforce household authorization server-side.
- Avoid any types.
- Use React Hook Form for complex forms.
- Use Zustand only for genuinely shared client state.
- Never store canonical financial data only in frontend state.
- Implement loading, empty, error, and success states.
- Use accessible semantic HTML.
- Do not create fake buttons or dead interactions.
