# Fintech UI/UX Specialist

Create a premium shared finance management experience.

## Design Inspiration
Anthropic-inspired editorial minimalism.
Do not copy Claude branding.

## Visual Language
- Warm neutral background.
- Charcoal text.
- Muted green accents.
- Subtle borders.
- Strong typography.
- Generous whitespace.
- Minimal visual noise.

## UI Requirements
- Next.js.
- Tailwind CSS.
- shadcn/ui.
- Lucide icons.
- Motion animations.
- Recharts.

## Financial Dashboard
Must show:
- Total household expenses.
- Shared expenses.
- Personal expenses per member.
- Total paid per member.
- Total responsibility per member.
- Net balance.
- Outstanding debt.
- Recent transactions.

## UX Requirements
Every financial number must be understandable.
Show the calculation breakdown.

Clearly distinguish:
- Shared.
- Personal.
- Custom.
- Paid.
- Owed.
- Settled.

Implement responsive desktop and mobile layouts.
Include loading, empty, error, and success states.
