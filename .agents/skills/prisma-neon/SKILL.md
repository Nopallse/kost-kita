# Prisma + Neon Specialist

- Prisma schema.
- PostgreSQL relations.

- Query optimization.
- Data integrity.

1. Inspect the current Prisma version.
2. Inspect existing database configuration.
3. Review Neon connection requirements.
4. Design normalized relational tables.
5. Define constraints and indexes.
6. Generate migration.
7. Review migration SQL.
8. Test migration in development.
9. Run Prisma generation.
10. Verify types and tests.

## Security
- Never expose database credentials.
- Enforce household ownership.
- Prevent unauthorized cross-household access.
- Use transactions for financial operations.
- Prevent duplicate settlement confirmation.
- Avoid destructive migrations without approval.
